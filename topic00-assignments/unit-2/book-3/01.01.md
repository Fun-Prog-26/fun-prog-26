# Programming Assignment - Formative

Your Programming Assignment will be worth 40%.
You will be asked to complete some of the earlier tasks of the assignment for submission by Week 10 (first week back after Easter). 

This is a formative assessment which means that no marks are awarded for this work. It is meant to get you started on the assignment and to ensure that you are on the right track. 

You are given you a full specification of the entire Programming Assignment (and the part of it to be submitted by Week 10). 

The details of what is required for the Formative Assignment is in the full spec in the Milestones section: 


## Formative Assignment (Milestone 1: Data modelling and parsing)

You should:
 - inspect the XML structure
 - define suitable Haskell data types
 - parse one XML file into an internal structure
 - demonstrate that quiz questions can be extracted successfully

Suggested evidence
 -draft ADTs
 - parser code
 - a simple .md file which contains a copy of the data

This should be submitted on Moodle before the start of Week 10, i.e. Sunday 12th April 2026.
