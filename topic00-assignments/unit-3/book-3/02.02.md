# Shuffle function 

One functionality you are asked to implement is the shuffling of questions. See below a function that takes a list and returns a shuffled versin of the list. 
```haskell
shuffle :: [a] -> IO [a]
    shuffle [] = return []
    shuffle xs = do
        i <- randomRIO (0, length xs - 1)
        let (front,(a:back)) = splitAt i xs
        rest <- shuffle (front ++ back)
        return (a : rest)
```

This function returns a shuffled list. It takes a random element from the list, puts it at front and repeats the process on the rest. 

## Properties of shuffled list. 
1. the lengths of the original and shuffled lists should be the same.
2. The same elements should appear in both. 

We would like to incorporate this into code 

```
prop_checkShuffle :: [Int] -> Bool
prop_checkShuffle xs =
  let shuffled = unsafePerformIO (Shuffle.shuffle xs)
  in length shuffled == length xs && all (`elem` shuffled) xs

```

This checks that both properties hold.
