# Using trace in functions


## Exercise 1
Write a recursive function to calculate factorial. Use trace to see how it works.

## Exercise 2
The following sort is bugged. Using trace to help you, fix it. 

~~~
sumList :: [Int] -> Int
sumList []     = 0
sumList (x:xs) =
  trace ("x = " ++ show x) $
    x + sumList xs + 1
~~~

## Exercise 3
The following sort is bugged. Using trace to help you, fix it. 
~~~
reverseList :: [Int] -> [Int]
reverseList [] = []
reverseList (x:xs) =
  trace ("x = " ++ show x) $
    reverseList xs ++ [x, x]
~~~
## Exercise 4
The following sort is bugged. Using trace to help you, fix it. 
~~~
sort :: Ord a => [a] -> [a]
sort ( x : xs ) = insert x ( sort xs )
insert :: Ord a => a -> [a] -> [a]
insert x [ ] = [ x ]
insert x ( y : ys ) = if  x <= y   then (x : ys)   else y : insert x ( y : ys )
~~~
